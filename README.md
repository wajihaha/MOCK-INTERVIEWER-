# 🎓 Smart Mock Interviewer — Global AI Career Readiness Simulator

**Built by Coding Club | Team: Haniya Ayaz & Wajiha Fatima**

**Smart Mock Interviewer** is a 100% free, browser-based AI career readiness platform built to help engineering and university students worldwide overcome interview anxiety and practice realistic technical and HR interviews before placement season.

---

## ✨ Key Features

- **13 Engineering & Industry Tracks:** Tailored technical and behavioral questions across *Software & CS, AI & Data Science, Electrical & Electronics, Mechanical, Civil, Chemical, Industrial & Manufacturing, Telecommunications, Mechatronics & Robotics, Biomedical, Textile & Materials, Petroleum & Gas,* and *Finance/Management/HR*.
- **Global & Regional Top Employer Presets:** Realistic company-specific interview styles for leading recruiters including *Systems Limited, 10Pearls, Folio3, K-Electric, Engro, PSO, SSGC, HBL, Unilever, Siemens, Schlumberger (SLB), Google, Microsoft, Amazon,* and more.
- **3 Realistic Interviewer Personas:** Practice with a **Friendly HR** (supportive), **Strict Tech Lead** (deep technical probing), or **Stress Tester** (challenging follow-ups).
- **Adaptive Follow-Up Engine:** Every question adapts dynamically to the user's selected role, company, resume/CV, job description, and previous answers—ensuring zero repetitive questions across practice sessions.
- **Corporate English & Hinglish / Roman Urdu Comfort Mode:** Students can speak or type naturally in mixed Urdu/English, and the AI translates their ideas into polished corporate English in the final evaluation report.
- **Cross-Device Voice Input & Text-to-Speech:** Speak answers hands-free using the browser Web Speech API and listen to questions read aloud.
- **Instant Rubric Scorecard & Shareable Readiness Badge:** Generates a `0–100` readiness score, Communication & Role Alignment metrics, question-by-question feedback with polished sample answers, a downloadable PDF report, and a LinkedIn-ready Readiness Badge image.
- **13-Track Instant Judge Demo:** Dedicated, one-click realistic demo scenarios for every single engineering and industry track for fast live demonstrations.

---

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS, Lucide Icons
- **AI Engine:** Groq Cloud API (`openai/gpt-oss-20b`) + Browser Web Speech API
- **Hosting:** Serverless Static Cloud Deployment (100% Free)
